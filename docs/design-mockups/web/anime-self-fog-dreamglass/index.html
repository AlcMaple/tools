风格来源

Color & Motif

梦可爱 Yume Kawaii

2010 年代日本原宿系「梦幻可爱」风格。提供整套粉彩色板（雾蓝 / 樱粉 / 香芋紫 / 星黄）与星星、月亮、花瓣母题。夜雾主题就是纱雾深夜画室的那扇窗。

Structure

玻璃拟态 Glassmorphism

半透明磨砂面板 + backdrop-blur + 顶部高光描边，承担全部内容承载。层叠的"雾面"呼应纱雾名字里的"雾"，也让海报墙在背景之上保持呼吸感。

Interaction

视觉小说 UI

Galgame / ADV 的界面语法：立绘在场感、名牌对话盒（全局通知都是纱雾说话）、选项肢式按钮（✦ 引导星 + 果冻回弹 hover）、文字打字机渐显。

色板 Token 切换右上角主题可对比夜雾 / 晨雾

交互规约（迁移到真实代码时同样适用）

  • 不挤布局：hover / 选中 / 临时提示（如「已保存」）只允许 transform、filter、光晕与绝对定位，禁止改变盒模型尺寸。
  • 不用原生控件外观：下拉一律自绘（.dd，浮层与触发器同宽）；滚动条统一 4px 细条样式。
  • 通知统一走对话盒：成功 / 失败一个组件，失败变珊瑚色，不做系统 alert。
  • 立绘只在两处大出面：整页登录 hero 与空状态半身像，功能页保持克制，避免"贴纸感"。
  • 动效克制：果冻曲线只给按钮与卡片入场，页面级只有粒子与极光斑缓浮；prefers-reduced-motion 下全部关闭。
