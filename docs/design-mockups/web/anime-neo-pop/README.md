# MapleTools Web：二次元编辑部交互设计稿

这是一套独立于生产代码的高保真交互原型，用于确认网页版下一阶段的统一视觉方向。主题定为：

> **二次元编辑部 × 孟菲斯新波普粗野主义**

视觉以暖纸张、硬边框、固定偏移阴影、胶带与几何拼贴构成；粉、青、紫、黄作为编辑标记色。和泉纱雾风格的本地角色图只作为编辑部代表角色出现，不依赖外部图片、字体、CDN 或网络请求。

## 审查范围

- `番剧周历`：星期筛选、追番切换与固定反馈区。
- `我的追番`：状态筛选、标题/别名/标签搜索、进度加减、继续播放、封面编辑与搜索加番。
- `在线播放`：从记录的当前集进入，切换稀饭 / Girigiri、线路、选集与播放状态。
- `设置`：账号、播放、数据三个面板；切换面板不会销毁已输入的状态。
- `邮箱登录`：邮箱发送验证码与 6 位验证码验证两步演示；交互稿验证码为 `062626`。
- 所有弹窗支持关闭按钮、点击遮罩和 `Esc` 关闭。

数据与播放均为静态演示。页面顶端的 `PROTOTYPE` 标识和稳定状态区明确说明该边界。

## 继承的产品行为

- “想看”不会仅因打开或编辑而变成“在追”；第一次执行 `+1` 后才转为“在追”。
- 进度达到总集数不会自动改成“看完”，状态仍由用户决定。
- 总集数留空表示连载中。
- 从追番卡进入播放页时使用卡片上记录的当前集；记录为 `0` 时才从第 `1` 集开始。
- 播放源仅展示当前网页版已有的稀饭 / Xifan 与 Girigiri，不从其他来源推断绑定。
- hover、选中、筛选和临时提示不会改变控件盒模型或推动周围布局。
- 没有原生 `select`；滚动区域使用统一细滚动条。

## 响应式边界

- 桌面：`232px` 固定编辑部侧栏，内容区独立滚动。
- 平板与手机：紧凑顶部品牌栏 + 固定底部导航。
- 所有核心触控目标至少 `44px`，提供 `focus-visible` 与 `prefers-reduced-motion` 处理。
- 设计目标包含 `1440×900`、`768px` 与 `390×844`，手机宽度不得出现横向溢出。

## 文件与使用

- `index.html`：语义结构与静态内容。
- `styles.css`：完整视觉系统与响应式规则。
- `app.js`：本地交互和状态演示。
- `assets/sagiri-mascot.png`：本地代表角色素材。

角色图由内置图像生成工具按本项目方向生成，是对和泉纱雾气质的原创风格化诠释，不是官方插画；成图已压缩为带透明通道的 `800×1200` PNG，仅供本设计稿审查使用。

直接在浏览器打开 `index.html` 即可审查；若浏览器限制本地行为，可在本目录启动任意静态服务器。

本设计稿没有修改 `web/src`、服务端播放器或桌面应用。审核通过前，它不会替代真实网页版实现。
