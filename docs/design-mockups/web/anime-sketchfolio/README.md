# 「纱雾画稿 Sagiri Sketchfolio」原型稿

网页版视觉重构的**第三版设计候选**：与 `anime-neo-pop`（孟菲斯·新波普粗野主义）和
`anime-self-fog-dreamglass`（雾境梦璃·玻璃梦境）并列，三选一后按选定稿重构 `web/src`，
重构后的线上效果必须与本目录 HTML 一致。**本质是原型稿**：布局自由重造（不参考现有项目布局），
可完整走通 退出 → 未登录公开周历 → 弹窗登录 → 追番 → 设置 的用户旅程。

## 怎么用（原型）

```bash
cd docs/design-mockups/web/anime-sketchfolio && python3 -m http.server 8932
# 打开 http://localhost:8932/ —— 即真实首页（番剧周历）
```

| 文件 | 功能 | 覆盖交互 |
| --- | --- | --- |
| `index.html` | 番剧周历（首页） | **日期章横滑选天 + 单日海报胶片**（每天 5 部、全周 35 部，scroll-snap 触摸原生、**无可见滚动条**）、追番圆章按钮**常驻**（不依赖 hover，未登录自动隐藏）、今日荧光笔+回形针、回到今天、刷新、NagBar；**登录弹窗**（AuthModal：左纱雾立绘栏 + 右表单，密码/验证码/注册/找回四模式、明文切换、倒计时、错误抖动、Google 按钮） |
| `tracks.html` | 我的追番 | **等宽卡片网格**（auto-fill 双列、卡片同宽同高；**不按更新日分组**——追番不全是新番，仍在连载且今天有更新的番贴「今天更新」小贴纸，完结/老番无）、步进器与进度条**钉同一行**；**加番弹窗**（显式入口：搜索 + 全量候选 + 一键加入，**列表定高 + 隐藏滚动条**）、**一体式步进器**（− EP n + 胶囊）、铅笔排线进度条、标签增删、页内搜索、**状态分段直点**（想看/在看/看完常驻胶囊组，替换原「···」下拉）、移出按钮 + 移除确认、同步、空态、エルフ立绘页尾驻场（手机端为页首内联） |
| `settings.html` | 设置 | 借书卡身份页、**纸口袋手风琴**五模块（hash 深链）、自绘下拉、换绑两步流、解绑、密码、密保、稀饭验证码（点图换一张）、行内保存反馈、退出登录 |
| `player.html` | 在线播放 | 播放/暂停（播放态进度动画）、**稀饭 ⇄ Girigiri 播放源切换**（换集保持）、线路列表切换、12 集选集网格（✓ 已看、当前集高亮、点击换集同步徽标） |

**布局骨架**（刻意区别于现有项目的顶栏+居中容器）：桌面 = 左「书脊」侧栏（索引贴导航 + 用户卡）；
移动 = 顶栏 + **底部标签栏**。立绘采用**单立绘驻场**（周历=纱雾、追番=山田エルフ、设置=千寿ムラマサ、
登录弹窗=纱雾、空态/头像=Q 版纱雾），带待机摇摆与点击弹跳；**不做轮播/拼贴**——官网没有连贯动作帧
素材，多姿势翻面被判定为无意义，真 GIF 需要模型或逐帧图（重构时可由用户自备素材接入）。

共享层：`css/tokens.css`（变量/字体/方眼纸底/网点·荧光笔语汇）、`css/sketch-ui.css`（组件）、
`js/app.js`（图标 sprite、登录态、便签 Toast、下拉、弹窗、倒计时、各页静态 mock 控制器）。
登录态在原型内用 localStorage 持久（`sketch-auth`），跨页一致；清掉即回到默认已登录视角。

## 风格定义（诚实版）

- **主体风格：手帐 / 剪贴簿（Journal & Scrapbook）**——网上可查的成熟设计风格：方眼纸底、
  和纸胶带装裱、拍立得照片、圆形印章、文件夹页签、借书卡、索引贴；面板不透明、无 blur、无光晕
- **装饰语言：少女漫画元素**——halftone 网点（漫画贴网技法，平面设计中常用纹理）、
  星芒 ✦、缎带标题、荧光笔划重点、细墨线描边；「纱雾画稿」只是这套组合的代号，不是自创风格名

**为什么是纱雾**：她是插画家（原作「エロマンガ老师」），画稿本/网点/印章是她的生产工具；
配色直接取自官方立绘实测色（青 #298B94 = 全身立绘外套、樱粉 #FDA9B9 = 半身像衣领、
银 #D6DAE1 = 发色）；她害羞话少 → 通知是「便签」不是弹窗轰脸。**单一光色主题（素纸），无明暗切换。**

**与另两稿的分界**：孟菲斯·新波普粗野主义 = loud 撞色几何；雾境梦璃 = 半透明玻璃 + 光晕；
本稿 = **哑光纸面 + 油墨 + 装订感**，材质隐喻完全不重叠。

## Token 速查

CSS 变量在 `css/tokens.css`（单主题）：

- **色**：`--paper/--paper-2/--card`（三级纸面）、`--teal`（主色·外套青）、`--sakura`（樱粉）、
  `--silver`（银发·描线）、`--gold`（荧光笔/看完）、`--lav`（标签）；文字 `--ink/--ink-sub/--ink-faint`；胶带 `--tape-*`
- **形状**：`--wob-1/2/3`（手绘抖动圆角，按钮/贴纸）、直角 `--r-card`（照片/面板）
- **阴影**：`--shadow-1/2`（纸叠纸双层小投影）+ `--shadow-stick`（贴纸按压）——**没有 glow**
- **字体**：Yusei Magic（拉丁手写，本地 woff2）+ 系统中文；标题/日期/集数用手写体，正文系统体
- **动效**：`--ease-stick`（贴纸落纸回弹）、`--ease-page`（翻页缓动）、`.rig` 立绘待机摇摆
- **漫画语汇工具类**：`.halftone/.halftone-wash`（网点）、`.hl`（荧光笔）、`.sparkle`（星芒闪烁）、`.title-sketch`（铅笔双线标题）

## 交互规约（重构时一并继承 AI_GUIDELINES 红线）

- **触摸优先：一切功能不依赖 hover**——追番按钮/详情/状态切换全部常驻直点，hover 样式统一收在
  `@media (hover: hover)` 里，**触屏设备一条都不会加载**（防手机点按后的粘滞 hover）；
  触控目标 ≥40px（追番圆章 44px、状态分段整组 47px）；横滑用 scroll-snap 原生手势
- hover / 临时提示只准 transform、颜色、阴影、绝对定位——**禁止改变盒模型尺寸**
- 下拉一律自绘（`.dd`，浮层与触发器同宽）；滚动条统一 4px；不弹系统层控件
- 全局通知统一走**便签 Toast**（纱雾头像 + 名牌 + 圆章，失败换樱粉描边）；**单例**——连续触发时
  后来的直接顶掉先来的，右下角永远只有一张，不堆叠
- 立绘出现位置：各功能页驻场立绘（带待机动作）+ 登录弹窗左栏 + 头像/空态 Q 版
- 动效克制：盖章落纸 / 翻页 / 便签滑入 / 立绘摇摆 / 星芒闪烁；`prefers-reduced-motion` 下全部关闭

## 迁移到真实代码（重构执行清单）

1. `web/src/index.css`：MD3 变量 → 本主题变量（RGB 三元组格式保持，供 Tailwind alpha 修饰符）；
   body 换方眼纸底 + 噪点覆盖层；圆角刻度按 `--wob-*` / 直角两档替换

4. 逐页顺序建议：`骨架 + 便签 Toast` → `AuthModal` → `CalendarPage` → `TracksPage` → `SettingsPage`，
   每页对照本目录同名 HTML 验收
5. 组件对照：`.dd` ↔ `Select.tsx` 扩展、`.toast-note` ↔ 新 Toast 组件、
   `.dstamp/.film/.poster/.trk-row/.pocket` ↔ 页面内组件；**无画布粒子层**
