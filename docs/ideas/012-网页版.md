## 不再重新讨论的决策

- **Web 是桌面功能子集，不是整端搬家**：本地扫描、文件操作、桌面下载/ffmpeg 不顺手搬来。两端各装依赖、各启动构建；不为了复用把根改成 workspaces。只改一端不动另一端，跨端协议才一起核对。
- **目录与片源分开**：BGM 负责搜得到、加得进；稀饭/Girigiri 负责在哪看。没有片源不等于没有番剧资料，绑定要明确确认。
- **服务器权威、缓存提速**：`localStorage` 不参与时间戳胜负；网页字段级修改，不冲掉桌面 `extra` 富字段；桌面整包同步不是自动双向 merge，不需要为这条覆盖通道另加删除墓碑。
- **上传冲突靠 revision，不靠设备时钟**：事务内比较 `baseRev`，不同返回 409；用户决定先拉取还是明确覆盖。保留 `extra.appOrder`，旧记录按既有添加时间恢复顺序；未知星期/日期不覆盖已知值。
- **本地索引保护上游**：搜索不为每个输入打 BGM；离线档没有封面需另外补；wiki 格式 infobox 与在线 JSON 不是同一格式。索引先校验再原子替换，失败不毁掉旧库，能报告索引陈旧。
- **元数据逐字段补空**：已有标签不代表日期/评分齐全；网络返回后重读记录，不覆盖用户刚写的数据。系统补全不 bump 用户追番 revision。
- **备份导入不是同步覆盖**：导入按条目更新时间合并、未出现的账号条目保留；他人备份不导其点评。ZIP 带本地封面，Markdown 只读；反馈不属于用户追番导出。

## 上线与维护时别重踩

- 历史实际落点是香港 VPS + Node + nginx + pm2，不是旧 Oracle/Vercel 设想；具体机器、价格、软件版本和可达性须现场确认。不是所有源都能从同一出口访问，也不承诺“视频零服务器带宽”。
- `DATA_DIR`、数据库、本地封面和密钥在部署目录外；发布不能清用户数据。数据库行与磁盘封面在单条、批量、同步、删除、备份/恢复所有路径都需一致，异步删图不能删掉后来的新上传。
- Node 只监听 loopback，反代提供 HTTPS；应用低权限运行、备份与应用隔离。排查 spawn EACCES 也看 cwd，备份任务别让 WAL/SHM 变成 root 所有。
- API 只在 `/api/*`，页面用 hash 路由，用户标识不挂根路径；未知 API 为 JSON 404。旧服务可能回 HTML 200，客户端要核对 Content-Type，跨端发布分别验同步 GET/POST。
- SSE 响应显式 `X-Accel-Buffering: no`，dev 逐字输出不等于反代后仍逐字。CSP 响应头和构建 meta 同时生效，blob 海报预览等新来源两处一起改。
- 下载先拿短效、用途锁定的票据，再用普通链接，兼容下载管理器不带 Cookie；格式用 `zip-md`，别用 query 中会变空格的 `+`。
- 移动端关键按钮常驻，不依赖 hover；固定导航避免动态 safe-area 参与布局，别用钉住 body 的补丁破坏原生下拉刷新。计数/提示不挤布局，字体/透明度/CSP 要看生产产物。
- 画稿装饰不代表业务统计：目前追番“今日功课”按 updatedAt，改标签也算动过；旧设置/福利上色实验已撤，不按旧效果图恢复它们。
