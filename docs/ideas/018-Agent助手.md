## 已经做到哪里

| 部分 | 当前结果 |
|---|---|
| 入口 | Web 的悬浮对话，PC/平板优先；隐藏面板不清会话，手机首期隐藏。角色语气不能盖过明确动作/错误提示 |
| 历史 | 登录账号的私有会话、消息、来源、动作记录可恢复；新建、重命名、归档、删除、导出；压缩不删除可见原文 |
| 上下文 | `/compact`、阈值压缩、摘要版本/编辑/恢复、固定消息与原文回填；偏好经用户确认才跨会话生效 |
| 数据 | 离线 BGM、已加载番剧资料、缓存周历、当前用户追番、公开点评与聚合；集数按本地放送日期推算并标依据，不当成源站实际更新 |
| 运行 | SSE、取消/显式恢复、工具/时间/token/费用预算；账号单活动回合；断线续读事件，不自动重放付费调用 |
| AI | 项目外部 API、已核准连接档案的 BYOK；fake 只用于测试。能力探测成功才算可连接，不以配置了 key 当可用 |
| 访客 | 仅临时标签页对话与公开白名单；无私人历史/偏好/写动作；刷新不恢复聊天，也不重置服务端反滥用预算 |
| 追番动作 | 模型只提预览；用户确认后事务写入、revision 冲突保护与权威回读。删除/下载/邮件/源站登录不进入工具集 |
| 播放动作 | 一张预览可组合“加/改追番 → 认片源 → 打开播放器”；每步失败停止后续，实际播放以页面事件和服务端回执为准 |

## 固定边界与关键决策

- **模型提案 → 用户确认 → 执行 → 权威回执**。工具 schema、用户权限、参数、版本和 actionId 由应用校验；模型说“成功”不是证据。跨域或缺事件只能 unknown，不拿截图代替播放成功。
- 模型只读本地/缓存资料，没有联网搜索、任意 URL、源码、shell、文件、Git、部署或浏览器操作工具。在线 BGM/片源请求由用户点击现有页面动作触发；缺资料不补造。
- 人格、用户文本、公开资料、BYOK 输出和摘要不能更改权限。摘要只描述事实与未完成项，不变成系统指令；未确认偏好不进长期记忆。
- 历史原文、事实/摘要版本、实际发送上下文分开保存。压缩先预算/整理/抽取，再规则和模型核验、补原文、分层汇总；失败/取消保留旧有效摘要。
- 有原生压缩适配器不等于所有供应商已经实测可用。`64k/128k/256k/1m` 是预算档位，实际取模型能力与费用预算内上限；1m 不等于每轮填满百万 token，也不等于低费用。
- 功能知识随运行版本/权限装配，不靠模型读源码；代码与说明共同构建/发布/回滚。旧会话下一轮重取快照，长回合动作前重验；版本失配暂停旧动作，不让旧摘要覆盖新能力。
- 项目 key 的连接探测可全站共享，发起者刷新只取消自己的等待，不能销毁共享探测；否则费用已经产生却丢掉结果。取消后未知费用不冒充零费用。
- 追番 `act-` 与播放 `pb-` 分表/分接口，彼此不可套用；待确认预览不阻塞继续提问，只限制会话破坏性变更。相同待确认提案复用 actionId，避免模型重试出重复卡。
- 打开标签要保留用户手势；带写入的组合动作走 POST，同步先开空标签再导航。写失败就停，不能先打开再假报写成功。普通打开与带写入动作不可共用无保护的 GET。
- 源绑定为全站事实，不能让模型或客户端任填片源 ID；候选保存在服务端动作行，客户端选下标，最终确认才 bind。稀饭已换新站，不再套用旧验证码流程；Girigiri 的验证码仍只走用户页面，不进入模型/聊天历史。

## 修过的错误，为什么测试曾没抓到

- token 估算曾把 UTF-8 字节当 token；费用预授权又装不下允许的工具轮数。测试要断言量纲/数量级和完整回合，不只断言 JSON 形状。
- SSE 终态漏 `actions`，于是流“正常完成”但卡片不出现；前后端分别通过不等于跨边界契约通过。
- 夹具复制工具清单，与生产各自变化；优先 import 生产常量/注入同一组装来源，不在顺手接口里另造数据真相。
- 共享探测绑定首请求的 signal，刷新误杀所有人的连接准备；测试必须包含发起者离开、其他等待者继续。
- 套件曾未跑完而其他 JSON 汇总看似全绿；检查计划条数、实跑条数与测试进程退出码。不要读 `cmd | grep` 的退出码冒充测试退出码。
- 这些是验证缺口的历史结论，不是架构永久正确的证明；继续检查契约、夹具单一来源和数量级。具体待办保留在 [019](019-Agent架构复盘.md)。
