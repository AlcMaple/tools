# MapleTools 使用场景：稀饭动漫、Girigiri 与个人追番管理

MapleTools 是 AlcMaple 开发的网页追番应用与桌面工具

[项目与下载说明](../README.md) · [在线使用](https://anime.alcmaple.cn/) · [桌面安装包](https://github.com/AlcMaple/tools/releases)

## 稀饭动漫（Xifan）搜索与下载

在桌面端打开「搜索下载」，选择稀饭源，输入番剧名称，选择剧集并加入下载队列。可管理暂停、继续和失败剧集；追番条目可以绑定观看来源。适合希望把稀饭搜索、番剧下载和追番记录放在同一应用中的用户

## Girigiri 动漫搜索、多源绑定与下载

桌面端支持 Girigiri 搜索及选集下载。同一追番条目可以记录不同来源的观看链接，方便在来源之间选择，而不必维护多份追番列表

## 个人追番管理

在「我的追番」管理观看状态、当前集数、标签和观看链接。可以从 Bangumi 条目添加番剧；网页版也支持手动记录后补全资料。番剧周历按星期展示本季更新计划，适合管理想看、在看和看过的番剧

这里的追番记录是应用自己的记录。Bangumi（BGM / 番组计划）为番剧资料来源，不能据此推断支持向 Bangumi 官方账号回写收藏

## Windows / macOS 本地番剧整理与播放

桌面端扫描选定的本地目录，提取缩略图并展示本地媒体，提供播放入口。资源管理器还可浏览文件并预览视频、图片和文档。安装包面向 Windows x64 和 macOS Apple Silicon；扫描缩略图及下载等功能依赖系统 ffmpeg

## 坚果云 WebDAV 同步追番数据

在桌面端设置坚果云账号和应用密码后，可以上传、拉取追番数据，并处理本地与远端的差异。适合在不同电脑之间保存和同步追番列表

同步对象是应用数据，不是视频文件。当前服务地址固定为坚果云；不宣称任意 WebDAV 服务兼容，也不宣称能从 WebDAV 挂载的视频目录直接播放

## 网页版与桌面版之间同步追番

桌面端登录网页版账号后，可通过追番同步入口上传或拉取记录。这与坚果云同步分别配置；不要把两者理解成自动联动的同一个同步服务

## 游戏阵容查询与妙语收藏

「锦囊妙计」提供作业查询、JJC / PJJC 换防、经典阵容及记录；「妙语库」收藏文字与图片形式的发言。这些桌面功能独立于追番，不要求用户只把应用用于动漫
