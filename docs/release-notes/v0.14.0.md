稀饭在线播放重做（后台安全检查、启动更快、报错更准），新增 B 站短信登录

> [!Tip]
> 已装旧版的用户：应用会自动检测并提示，点「重启安装」即可。

> [!Note]
> 本应用依赖系统 ffmpeg，请确保已安装并加入 PATH。
> Windows 从 [ffmpeg.org](https://ffmpeg.org/download.html) 下载；macOS 推荐 `brew install ffmpeg`。

> [!Tip]
> macOS 首次打开提示"无法验证开发者"时，请右键 App → 选择"打开"，
> 或执行 `xattr -d com.apple.quarantine /Applications/MapleTools.app`。

> [!Warning]
> 当前为开发中版本（v0.x），界面与数据格式可能在后续版本调整。

### 新增

**Bilibili**

- 新增短信登录入口（手机号 + 验证码），与扫码登录并列，设置页与播放页都能进

**在线观看**

- 播放器标题栏显示当前播放的集数

### 优化

**稀饭动漫**

- 稀饭在线播放启动更快
- 拖动播放进度条时响应更跟手

**动漫信息**

- 重新设计动漫信息详情页

**BGM**

- 搜索无精确匹配结果时，改为显示相关度最高的前三个候选

### 修复

- 修复稀饭源站临时故障（网关超时）时报错文案，不再误导性地显示成"网站数据和预期不一致，可能它改版了"
- 修复稀饭源无法在线观看

### 使用提示

- 稀饭在线播放遇到问题时，可在 设置 → 关于 →「打开日志目录」查看 `main.log`，其中记录了安全检查、请求、验证码等各阶段的进度，方便定位卡在哪一步
- 嗷呜源仍下线，搜索页里会显示为不可选状态
