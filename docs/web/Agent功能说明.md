# Web Agent 功能说明

本文随 Web 功能代码维护，供后续服务器功能知识清单接入使用。**当前实现到阶段 5：PC / 平板界面及六个本地只读工具已接入，功能快照包含当前 Web 入口，手机隐藏；真实回答模型及访客对话留在阶段 6。** 实际可用能力仍以服务器正在运行的代码、开关和账号权限为准。

## agent.history：个人会话历史

**用途**：保存自己的 Agent 会话，换一个已登录客户端仍可读取已经保存的内容。

- 新对话先保留在当前界面；首次发送才写入历史。支持列表、重命名、逐条归档、恢复、清空、删除和 JSON 导出。
- 首条消息按内容提取简短标题，仅生成一次；手动改名优先，后续消息和清空后的续聊不再自动改名。
- 保存用户消息、助手已生成正文、来源卡片、工具摘要和动作状态；部分回复也可保留。
- 会话默认私有，不进入公开追番大厅；仅当前登录账号读取和管理。
- 两端同时修改时先检查版本，旧请求提示刷新，不覆盖较新的内容；重复发送同一次创建/消息请求不重复保存。
- 归档后保留阅读和导出，恢复后再继续追加；进行中的回复或待完成动作须先结束或取消，再清空、删除或归档。
- 清空会移除本会话内容，但保留会话名称和当前番剧；删除移除整本会话。操作前先导出要保留的记录。
- 导出仅包含已保存的可见内容与摘要，不包含应用凭据、系统提示词或原始模型/工具协议包。用户自行输入的正文会原样保存，请勿在聊天中粘贴密钥。

**当前入口与能力映射**：

| 项目 | 当前状态 |
|---|---|
| 会话管理 | `/api/agent/sessions` 服务端接口已实现 |
| 用户消息保存 | 会话下的 `messages` 接口已实现，只接收用户正文 |
| 助手正文 / 来源 / 动作摘要 | 仅供服务端写入，不开放浏览器伪造接口 |
| 右下角聊天入口 / 历史列表界面 | PC / 平板悬浮手帐已接入 |
| 上下文压缩 / 偏好 | 阶段 2 服务接口与适配器已实现，见下文 |
| 普通模型回答、追番执行、播放打开 | 后续阶段实现，本阶段不触发 |
| Agent 模型工具 | 会话管理由应用处理，不新增模型执行权限 |

**容量与频率**：单账号最多 200 本会话、每本最多 10,000 条消息；正文及摘要合计每本 10 MiB、每账号 50 MiB。单条正文最多 32,000 字符，请求最多 128 KiB。读取 120 次/分钟、写入 30 次/分钟、导出 2 次/分钟，达到限制保留既有内容。

修改本功能时同步更新用途、入口、限制和实现状态；尚未部署的变更不提前描述为线上可用。

## agent.context：上下文压缩与确认偏好

**用途**：整理下一轮需要发送的上下文，保留完整聊天原文；用户确认的偏好可跨会话使用。

- 支持手动 `/compact`、压缩状态查看与取消；准备下一轮上下文时达到有效窗口的 78% 可启动同一压缩流程。阶段 3 的运行循环已调用该准备入口；真实回答模型和聊天界面仍按后续阶段接入。
- 默认保留最近 10 轮、用户固定的原文、未完成动作及尚未回应的用户消息；可按关键词或已有来源/动作编号回填旧原文。
- 摘要生成先抽取、独立核验，再分层合并；缺失锚点回填后再次检查。失败、取消、预算不足或资料变动时，旧活跃摘要保持不变。
- 摘要可查看、编辑并恢复旧版；编辑/恢复都产生新版本，不删除聊天。原生 opaque 状态只供服务端续传，不作为聊天或导出内容。
- 偏好固定为说话方式、喜欢的标签、避开的类型和推荐重点四项，每类一个值。切换分类分别编辑，一次保存四项；保存即为本人确认，留空表示默认。清空或删除某段会话不影响这些账号设置。
- 有效窗口取所选档位和模型上限中较小值。默认自适应，固定内容确实需要更多空间时才扩档；用户明确固定档位后不自动突破。

**当前入口与能力映射**：

| 项目 | 当前状态 |
|---|---|
| 上下文准备 / 手动压缩 | 会话下的 `context/prepare`、`compact` 接口；精确 `/compact` 命令可转入压缩任务 |
| 摘要版本 / 原文固定 / 偏好 | 会话下的 `summaries`、消息 `pin` 及账号级 `preferences` 接口 |
| 默认服务器模型联调 | 需要维护者显式开启；没有自动 fake 或免费模型替代 |
| OpenAI / Claude 原生适配、DeepSeek 应用摘要 | 适配器与受控响应测试已完成；真实模型质量仍需后续验收 |
| BYOK 配置和连接入口 | 阶段 6 接入；当前有相同规则下的协议适配与测试，不切换到别的模型代用 |
| 偏好卡、压缩按钮及浮层状态展示 | PC / 平板悬浮手帐已接入，实际压缩仍取决于模型配置 |

每个账号同时只进行一次压缩，最长 10 分钟；单任务最多 48 次模型操作，并有按窗口计算的 token 预留上限。每本会话保留最近 30 个摘要版本、100 条压缩记录；当前设置最多四项，每类一个值；旧卡片数据读取时按分类取最近确认值，保存时合并，不由读取操作删除原记录。完整聊天历史不因压缩而裁掉。

## agent.run：只读运行循环与进度恢复

**用途**：服务端按轮准备上下文、校验模型请求与只读结果，保存进度；断开聊天连接不等于取消任务。

- 同账号同时只运行一轮。每轮最多 12 轮工具调用、每轮工具请求最多 4 个；已注册六个本地只读数据工具；真实回答模型尚未接入。
- 正文片段、来源、工具摘要与用量通过校验后落入账号历史；模型的额外工具、身份字段、伪造来源、写入或播放请求不会执行。正文只作为文本数据展示。
- 3 分钟提示较慢、8 分钟标记长任务、10 分钟保存为可继续状态；累计 30 分钟后要求新回合。用户取消保留已生成片段，旧响应不覆盖终态。
- 查询超时单独记录；模型和工具请求不由传输层自动重试。SSE 的 15 秒 heartbeat 与模型进展分开，60 秒无进展会暂停；订阅断开后可按事件序号恢复，客户端最多重连 2 次，HTTP 错误不重试。
- 回合列表供另一端重新找到活动或暂停记录。恢复需要用户请求和当前会话 revision；有更新的用户问题时，旧回合停止恢复，避免回复错位。
- 每轮开始和恢复时装配服务器功能快照；下一次模型/工具调用及结果接收前再次检查版本和账号权限，变更后暂停旧回合，待用户明确继续。
- 代码与功能说明在构建时生成共同指纹，服务启动后固定为本次运行快照。只更新仓库或磁盘不会替换运行中的版本；代码和说明不匹配时标记待同步，不引用其他版本补造功能。
- 当前快照覆盖已登记 Web 功能与六个只读工具；邮箱、Google、福利等按运行配置及账号资格过滤。模型对实际功能的理解仍需后续真实评测。

**当前入口与能力映射**：

| 项目 | 当前状态 |
|---|---|
| 功能快照 | 登录后 `GET /api/agent/knowledge`；按运行版本、开关和账号能力生成 |
| 创建 / 列表 | `POST / GET /api/agent/sessions/:sessionId/runs`；列表使用时间和 ID 双游标 |
| 回合状态 / 进度 | `GET /api/agent/runs/:runId` 及其 `events` 接口；只返回可见元数据 |
| 用户取消 / 恢复 | 回合下的 `cancel`、`resume`；不因连接重建重放模型调用 |
| 真实回答模型 / 数据工具 | 六个只读工具与账号会话绑定已接入；真实模型仍未就绪，普通运行没有 fake 代答 |
| 浮层及刷新按钮 | 已接入；已显示旧页面提示，保留草稿并由用户点击刷新 |

每会话最多保存 100 个回合，每回合最多 2,048 条事件及 256 KiB 内部检查点；事件与检查点合计每回合 2 MiB、每账号 10 MiB，并参与历史总空间检查。每账号最多 2 条 SSE 订阅。清空/删除会话会清理其回合和事件，独立确认的偏好保持原有语义。

## agent.chat：纱雾助手

**用途**：在当前页面旁打开一页小手帐，查看历史、来源与进度；收起不会取消已开始的回合。

- PC / 平板右下角 52px 纯头像入口，面板约 440px 宽并按可视区域收缩；独立固定浮层，不挤占主内容，平板避开底部导航。手机入口和卡片按钮隐藏。
- 会话列表支持切换、分页、新建、重命名、归档、清空、删除和导出；清空/删除有独立确认，不把收起解释为取消或删除。
- 消息只按文本展示，来源卡、工具摘要、固定原文与已有动作状态分别呈现。待确认动作不提前开放执行；追番/播放确认仍在阶段 7 / 8。
- 主输入保留未发送草稿，支持建议问题、Enter 发送、Shift + Enter 换行和输入法组合状态；会话草稿分别保存于当前账号的内存，退出账号清理。接口归属不匹配时不读取返回正文；跨标签页账号变化会先清理旧界面，再向服务器确认身份。
- SSE 支持进度、部分正文、未读、取消、暂停恢复和断线后重新读取；终态先回读权威消息与 revision，再开放依赖新版本的操作。
- 压缩按钮、`/compact`、任务状态/取消、上下文档位、摘要版本查看/恢复及四项偏好设置已接入；模型不可用时说明状态并保留原文，不显示假回复。
- 周历、我的追番、公开卡片及详情可通过按钮带入当前番剧；chip 可清除或通过另一张卡片切换。带入已在页面上的 ID / 标题和已知年份、集数、标签；未提供字段保留未知，不为按钮额外请求在线资料。
- 找番失败时可由用户打开原有普通搜索；点评/片源入口按已知上下文与资格展示，目标追番页再次校验。没有模型自动导航、发布、解析或播放。
- 旧页面提示仅要求用户点击刷新；有草稿时先提示收好，不擅自重载。开屏就绪通知与首次公告分开，刷新、跳过开屏及减少动画设置不隐藏入口。

**当前可测试内容**：启动 Web 后可以测试浮层、历史、草稿、上下文 chip、偏好与状态。真实回答模型仍在阶段 6，当前默认输入保留为草稿，发送按钮保持禁用并通过提示说明模型未接入，不常驻“对话准备中”横幅。完整站点知识 / 真实只读数据已在阶段 5 接入，自动化脚本可独立验收。

### 阶段 4 实机反馈修订（2026-09-08）

- 头像复用原图集的顶部正面区域，仅显示单张脸；入口不再带标题、副标题或展开箭头，运行及未读状态浮在头像边缘。
- 对话、历史、新建、偏好及设置入口保持一致；短视口保留导航，通过顶栏“对话”直接返回，不另设重复返回按钮。设置只管理当前会话，不重复顶栏或常驻刷新按钮；未发送的对话不显示归档入口。
- 偏好用于后续回答和推荐：四类分别输入，点击“保存”一次提交；空白为默认。没有添加列表、待确认卡或管理员审核，分类切换保留各自内容。
- 删除装饰性说明与备忘录式文案；上下文入口直称“上下文”，整理动作称“压缩上下文”。真正版本过期时仍显示更新提醒，刷新草稿须显式确认。

- 保存偏好通过 `PUT /api/agent/preferences/settings` 原子替换四项，按账号版本检测冲突；失败不部分保存。旧卡片接口保留兼容但拒绝重复分类。
- 历史列表在服务端过滤从未发送的空会话（不删除旧数据），每项提供独立归档/恢复入口。

## 阶段 5：本地数据与功能知识

六个工具只在服务器白名单中执行，无模型可调用的任意 URL、SQL、shell、截图或文件接口；未新增绕过运行循环的公开工具执行 HTTP 端点。真实回答仍在阶段 6，当前通过 `npm run test:agent-data` 验收。

| 工具 | 实际来源与边界 |
|---|---|
| searchOfflineAnime | 本机只读 BGM 索引及本地补充表；标题/别名子串、精确标签、年份、集数和标签相似筛选，筛选后排序截断。索引缺失返回 CACHE_MISS，不调用开发代理或在线搜索；未知集数不匹配集数上限，完结条件返回 CONTEXT_MISSING，不按年份或集数猜测。 |
| readCurrentAnimeContext | 只读当前账号、当前会话由页面按钮带入的结构化快照。载荷与番剧 ID 必须一致，切换 ID 清除旧载荷；文字视为不可信资料，不变成指令或权限。未提供简介不自动读取详情。 |
| readCachedCalendar | 只读现有内存/磁盘周历缓存，按星期筛选；缺失明确报错、14 天过期照实标记，不触发刷新。 |
| listMyTracks | 当前账号的动画追番、进度、状态、用户标签与 tracks_rev；不返回 extra、凭据、封面路径或另一个账号的数据，也不触发资料补全。 |
| listPublicReviews | 同时满足作者公开开关、已发布、对应作者动画追番仍存在；按番剧、模式、剧透上限筛选。不读取草稿或问题答案。 |
| aggregatePublicData | 预定义公开用户、动画追番、点评、推荐计数；可按番剧和状态过滤。未过滤的公开用户数包含开启公开但没有动画条目的用户；内容统计只计仍关联公开动画追番的发布内容。 |

- 查询有参数、数量、时间、身份和输出合同校验；来源携带读取时间。缺失字段不猜测，数据损坏给明确错误。公开开关或发布状态变化后下一次查询重新检查。
- 页面快照随会话 revision 更新，字节计入历史额度；清空会话同时清除该快照，保留当前番剧 ID。只读工具本身不写库或网络；用户点击带入资料属于已有会话更新操作。
- 访客仅准备周历缓存、公开点评和公开聚合三个工具及公开功能知识合同；离线搜索、私人追番和持久会话不授予访客。此阶段没有开放访客聊天路由或真实模型。
- 代码、功能登记、已审查路由清单及功能说明一起维护。新增路由、删除入口或说明漂移会阻断构建；维护者核对业务语义后运行 `npm run sync:agent-guide` 同步说明段和路由清单，构建不自动掩盖遗漏。
- 构建输出 `server/agent-guide.json` 与发布指纹；运行时核对代码和说明产物。部署应包含本次构建的 server 产物，缺失或损坏时知识状态为待同步。磁盘更新不替代进程已经加载的版本；语义是否准确仍由开发验收确认。
