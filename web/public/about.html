追番、找番，整理你的观看记录

MapleTools 将个人追番管理、番剧周历与多源观看放在一起。桌面版还提供动漫搜索下载、本地媒体管理和日常实用功能

打开网页版下载 Windows / macOS 版

个人追番稀饭与 Girigiri周历与 Bangumi本地媒体坚果云同步更多工具

个人追番管理

在「我的追番」管理观看状态、当前集数、标签和观看链接。可以从 Bangumi 条目添加番剧；网页版也支持手动记录后补全资料

稀饭动漫（Xifan）搜索与下载

在桌面端打开「搜索下载」，选择稀饭源，输入番剧名称，选择剧集并加入下载队列。可管理暂停、继续和失败剧集；追番条目可以绑定观看来源

Girigiri 动漫搜索、多源绑定与下载

桌面端支持 Girigiri 搜索及选集下载。同一追番条目可以记录不同来源的观看链接，方便在来源之间选择，而不必维护多份追番列表

番剧周历与 Bangumi 资料

按星期查看本季新番更新计划，浏览 Bangumi（BGM / 番组计划）提供的番剧资料。桌面版「动漫查询」支持查找条目及详情

追番记录保存在应用中，Bangumi 提供番剧资料；两者的收藏记录分别管理

Windows / macOS 本地番剧整理与播放

桌面端扫描选定的本地目录，提取缩略图并展示本地媒体，提供播放入口。资源管理器还可浏览文件并预览视频、图片和文档

安装包面向 Windows x64 和 macOS Apple Silicon；扫描缩略图及下载等功能依赖系统 ffmpeg

坚果云 WebDAV 同步追番数据

在桌面端设置坚果云账号和应用密码后，可以上传、拉取追番数据，并处理本地与远端的差异。适合在不同电脑之间保存和同步追番列表

同步对象为追番等应用数据，视频文件保留在本地；WebDAV 当前对接坚果云

网页版与桌面版之间同步追番

桌面端登录网页版账号后，可通过追番同步入口上传或拉取记录。网页版账号同步与坚果云同步分别配置

游戏阵容查询与妙语收藏

「锦囊妙计」提供作业查询、JJC / PJJC 换防、经典阵容及记录；「妙语库」收藏文字与图片形式的发言。这些桌面功能独立于追番

Anime tracker for web, Windows and macOS

MapleTools by AlcMaple provides personal anime watchlists, episode progress, seasonal calendars and Bangumi metadata. The desktop app adds Xifan, Girigiri and Aowu search/downloads, a local media library and Jianguoyun WebDAV data sync.
